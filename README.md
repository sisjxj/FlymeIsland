# Flyme Island

Flyme Island 是面向 Flyme / LSPosed 的实验性灵动岛模块，把已选择的应用通知、媒体播放和充电状态集中到摄像头附近。设置界面的分类方式参考了 [FlymeDuo](https://github.com/leyodr9000/FlymeDuo)，本项目独立实现。

> 目前为实验版本，主要针对魅族 21 Pro、Flyme 12.7 / Android 16 开发。不同机型及系统更新可能存在差异；请保留可回退的版本。

当前版本：**v0.56 开源预览版**。来电三级视图、按钮和触摸区域仍需真机验证，不应替代系统来电界面。

## 功能

- 自选应用通知、优先级与旁侧小胶囊；默认不选应用。
- 系统媒体会话、播放控制、可选波形和封面；播放器能力由各应用提供。
- 充电状态、外观尺寸和展开卡片摄像头避让。
- 魅族系统来电实验：接听、拒接、挂断、免提和三级尺寸；锁屏仍使用系统界面。
- 设置页面提供手动检查 GitHub 发布和项目入口；不自动下载或安装。

## 使用

1. 安装匹配签名的 APK，启用 LSPosed 模块，勾选「系统界面」。Aicy 互斥需要同时勾选 Aicy 助手作用域。
2. 重新加载 SystemUI，并在应用中启用灵动岛、授予通知读取权限、选择需要接入的应用。
3. 在真机检查通知、媒体、锁屏恢复以及其他应用的触摸操作。

## 隐私与权限

通知内容仅在设备上处理；预览可关闭。选择播放音频捕获时，系统会要求相应授权；应用不会将通知正文或音频上传到项目服务器。手动检查更新会访问 GitHub。

## 构建

需要 JDK 17、Android SDK 36 和 Gradle 8.13：

```sh
gradle :app:assembleDebug
```

CI 调试签名不同于个人设备已有签名；不同签名的 APK 不能覆盖安装。发布签名密钥不得提交到仓库。
